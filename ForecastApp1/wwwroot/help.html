Вход и сеанс

  • Откройте страницу входа и авторизуйтесь под выданной учётной записью.
  • При истечении сеанса или при обращении к API без авторизации браузер перенаправит снова на вход.
  • Доступ к отдельным действиям зависит от ролей (например, администратор и бухгалтер). Если кнопка или раздел недоступны по правам, сервер вернёт отказ.

Требования к файлу импорта (Excel)

Формат и размер

  • Нужен файл .xlsx (Excel в формате Office Open XML). Старый бинарный .xls не подойдёт.
  • Максимальный размер загрузки задаётся в настройках сервера (по умолчанию около 50 МБ).

Листы книги

  • Обрабатываются все листы, кроме тех, в имени которых (без учёта регистра, с нормализацией букв) встречается «readme» или «ожидаем» — такие листы пропускаются (служебные / пояснительные).
  • На одном листе может быть несколько блоков данных: сначала строка заголовков с распознаваемыми колонками, ниже строки; затем при смене структуры снова может идти новая строка заголовков.

Строка заголовков

Система ищет строку, где по ячейкам удаётся сопоставить хотя бы два известных поля. Названия колонок можно писать по-русски или по-английски — распознаются синонимы (примеры ниже). Пустые строки между блоками допустимы.

Даты в ячейках могут быть в виде текста (dd.MM.yyyy, yyyy-MM-dd и др.), как дата Excel или как серийный номер даты Excel. Суммы — числом; допускается запятая как десятичный разделитель и пробелы в записи числа.

Типы строк (что должно быть заполнено)

Каждая строка данных относится к одному типу, если в ней присутствуют нужные поля после сопоставления заголовков:

Тип Обязательные поля (смысл)
Поставщик Код поставщика, наименование; без номера договора, даты долга и данных отгрузки в той же строке.
Договор Код поставщика, внутренний номер договора; без суммы долга и без номера документа отгрузки.
Условие оплаты Отсрочка (дней); плюс внутренний номер договора или поле, ссылающееся на договор для условия.
Долг (снимок) Дата долга, сумма долга, код поставщика, внутренний номер договора.
Отгрузка Номер и дата документа отгрузки, сумма отгрузки, код поставщика, внутренний номер договора.
Заказ Номер заказа, код поставщика, внутренний номер договора; без номера документа отгрузки в той же строке.

Примеры подписей колонок (не полный список)

Достаточно, чтобы заголовок совпал с одним из вариантов или содержал длинную фразу-синоним:

  • Код поставщика: «код поставщика», «код», supplier code…
  • Наименование поставщика: «наименование поставщика», «поставщик», name…
  • Внутренний номер договора: «номер договора», «договор», internal contract…
  • Дата / сумма долга: «дата долга», «сумма долга», debt…
  • Отгрузка: «номер документа отгрузки», «дата отгрузки», «сумма отгрузки»…
  • Отсрочка: «отсрочка», «дней отсрочки», payment delay…
  • Период условия: «действует с», «действует по», valid from / to…
  • Заказ: «номер заказа», order…

Загрузка и фиксация в базе

  1. На странице Импорт выберите .xlsx и нажмите загрузку. Откроется предпросмотр пакета.
  2. Дождитесь статуса разбора. При ошибках чтения файла в пакете появятся блокирующие сообщения.
  3. Запустите проверку: система сравнит staging-данные с уже загруженными справочниками и правилами целостности.
  4. Исправьте исходный Excel при необходимости и загрузите новый пакет либо устраните замечания в данных.
  5. Выполните фиксацию (commit): данные переносятся в рабочие таблицы (поставщики, договоры, долги, отгрузки и т.д.). При необходимости доступен откат пакета — уточняйте у администратора.

Разделы сайта

Главная
Краткая информация о текущем пользователе и ролях.
Справочники
Поставщики, договоры, условия оплаты — просмотр и ведение (по правам доступа).
Долги / Отгрузки
Просмотр загруженных снимков долгов и фактических отгрузок.
Аудит
Журнал действий (импорт, расчёты и др.) — если раздел доступен вашей роли.
Админ
Администрирование пользователей — только для администраторов.

Расчёт, график платежей и отчёты

  • Расчёт: укажите дату расчёта. Поля поставщика и договора необязательны: можно сузить расчёт. В полях допускаются внутренние id из базы или код поставщика / внутренний номер договора — как в справочниках.
  • График: таблица строк графика для выбранного запуска расчёта (номер runId из истории на странице расчёта).
  • Отчёты: диаграммы по всем неархивным расчётам: круговая — доли по поставщикам; столбчатая — суммы по месяцам (сводно по всем или по одному коду поставщика, если он указан). Дополнительные выгрузки JSON на той же странице требуют отдельного ввода runId.

Вопросы по корпоративным правилам загрузки и ответственности за данные — к администратору системы.

Справка для бухгалтера

Короткая инструкция по загрузке файла, расчету графика и работе с ошибками.

1. Для чего нужна система

Система помогает: загрузить данные из Excel, проверить файл, рассчитать график платежей поставщикам и посмотреть отчеты.

2. Как загрузить файл

  1. Откройте раздел Импорт.
  2. Выберите Excel-файл.
  3. Нажмите «Загрузить и проверить».
  4. Дождитесь завершения проверки.
  5. Если ошибок нет — нажмите «Подтвердить и сохранить данные».
  6. Если есть ошибки — исправьте файл Excel и загрузите его снова.

3. Какие данные должны быть в Excel

  • поставщик;
  • договор;
  • дата долга;
  • сумма долга;
  • номер отгрузки;
  • дата отгрузки;
  • сумма отгрузки;
  • условия оплаты.

4. Что означают статусы загрузки

  • «Ожидает подтверждения» — файл проверен, но данные еще не сохранены.
  • «Данные сохранены» — данные уже попали в систему.
  • «Найдены ошибки» — файл нужно исправить.
  • «Загрузка отменена» — данные из этого файла не используются.

5. Как выполнить расчет

  1. Откройте раздел Расчет.
  2. Выберите дату расчета.
  3. При необходимости укажите поставщика или договор.
  4. Нажмите «Рассчитать график платежей».
  5. Откройте результат в разделе График.

6. Как читать график

Колонки в таблице:
  • поставщик;
  • договор;
  • документ отгрузки;
  • сумма к оплате;
  • дата по договору;
  • прогнозная дата платежа;
  • предупреждения.

7. Что делать при ошибках

  • Не найден поставщик — добавьте его в справочник.
  • Не найден договор — проверьте номер договора.
  • Неверная дата — исправьте формат даты в Excel.
  • Запись уже есть — проверьте, не загружали ли вы этот файл раньше.

8. Частые вопросы

  • Можно ли загрузить файл повторно? — Да, но проверьте, чтобы не создать дубли.
  • Что делать, если в файле только справочники? — Загрузите файл как обычно, затем подтвердите сохранение.
  • Что делать, если нужно пересчитать график? — Запустите новый расчет с нужной датой.
  • Можно ли удалить старые данные? — Обратитесь к администратору.
  • Почему дата платежа перенеслась? — Дата могла попасть на выходной или быть раньше даты расчета.
  • Почему часть долга не попала в график? — Не удалось связать долг с отгрузками или не хватает данных.
